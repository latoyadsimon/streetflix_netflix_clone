# Streetflix (NetflixForTheStreets)

A catalog + watchlist of free, fully playable titles with a street-graffiti look.

- `front-end/` — React 19 + Vite SPA. `cd front-end && npm install && npm run dev`. Needs `front-end/.env.local` with `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY`.
- `supabase/` — Postgres schema (`schema.sql`), seed data, user stories and ERD.

See `CLAUDE.md` for architecture and conventions.
