Netflix Clone — User Stories
1. Home Page (/)
As a viewer, I want to see featured movies and popular TV shows, so that I can quickly discover something to watch.
2. Browse Movies (/movies)
As a viewer, I want to browse movies by genre, so that I can find movies that match my interests.
3. Browse TV Shows (/tv-shows)
As a viewer, I want to browse TV shows by genre, so that I can discover series I might enjoy.
4. Title Details (/titles/:id)
As a viewer, I want to view a movie or TV show's details, so that I can decide whether I want to watch it or add it to my watchlist.
5. My Watchlist (/watchlist)
As a viewer, I want to view and manage my saved movies and TV shows, so that I can keep track of the content I want to watch.
6. Search Results (/search?q=:query)
As a viewer, I want to search for movies and TV shows by title, so that I can quickly find specific content.
